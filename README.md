#Diary App - React Native

Aplikasi buku harian sederhana untuk mencatat keseharian dan *mood*, dibuat menggunakan React Native dan Expo.

#Fitur
* Menampilkan daftar catatan buku harian.
* Warna bingkai kartu berubah otomatis sesuai *mood*.
* Menggunakan struktur komponen yang rapi (`DiaryCard`).
* Menampilkan avatar profil dan gambar *mood* (dari internet & penyimpanan lokal).
